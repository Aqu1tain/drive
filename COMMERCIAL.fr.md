# Licence et usage commercial

Drive est un logiciel au code consultable, pas un logiciel libre. Le code est public pour que vous puissiez vérifier ce qui tourne sur votre serveur, sous la [PolyForm Strict License 1.0.0](LICENSE).

## Ce que vous pouvez faire

- Installer et utiliser Drive à des fins non commerciales : pour vous, un loisir, une association, une école, un organisme public.
- Lire le code et le lancer pour vérifier son fonctionnement.

## Ce que vous ne pouvez pas faire

- Modifier Drive, en tirer une œuvre dérivée ou le redistribuer, modifié ou non. GitHub permet à chacun de forker un dépôt public, mais un fork ne donne aucun droit d'utiliser, de modifier ou de redistribuer cette copie.
- L'utiliser à des fins commerciales sans licence : en entreprise, pour une activité rémunérée, comme service vendu à des clients ou comme hébergement payant.

## Obtenir une licence commerciale

Écrivez à [contact@corentinrenard.com](mailto:contact@corentinrenard.com) en précisant l'organisation, l'usage prévu et le nombre d'utilisateurs. Drive pour les Organisations, pour les équipes où plusieurs personnes gèrent des fichiers, fonctionne avec une clé de licence : voir [docs/organizations.fr.md](docs/organizations.fr.md). Les fonctionnalités qui demandent une clé ne peuvent être utilisées qu'avec une clé valide.
